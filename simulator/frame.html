The Filter — simulator

402 × 874pt, the size the design doc is drawn at.

What this is

The real app. App.tsx, src/screens and src/components compiled by Expo for web through react-native-web — the same source the iOS build uses. Change a component, run npm run simulator, and the change is here.

What it does not reproduce

  • The Browse tab has no WebView. A browser cannot frame x.com or instagram.com — they refuse it — and a cross-origin frame is opaque anyway. Browse shows an explanation and offers a bundled sample page, which the genuine content script and engine do filter end to end.
  • Lockdown navigation blocking is not exercised. It hangs off a native WebView hook. Its allowlist is covered by tests/browse.test.ts.
  • Feeds are local samples. Real RSS and Reddit endpoints send no CORS headers, so a browser cannot read them. The phone can.
  • Blur is CSS, not a real iOS blur, fonts are the browser's, and there is no haptics, share sheet, or clipboard permission prompt.
  • Safe-area insets are faked by this page. A browser reports them as zero, so the frame pads the app's root by the iPhone 16 Pro's 59pt and 34pt. The app itself is unchanged.

Note

App state lives in this browser's localStorage, exactly as it lives in AsyncStorage on the phone. "Reset app data" clears it and re-seeds the sample feeds.
